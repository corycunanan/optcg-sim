## Printed payment and replacement

The initial full printed sequence is an all-or-nothing permission gate (8-3-1-1/3). Earlier ordinary payments may supply later resources. Mode8 enumerates exact legal DON identities and all meaningful variable amounts; omitted variable return means one-or-more, while numeric nonpositive DON repetition performs no movement/event (1-3-2-2). State restrictions intersect. Active/rested DON requirements exclude given DON under4-4-2. Generic DON-minus includes Leader, Character and cost areas (8-3-1-6/10-2-10-1), without Stage attachments.

For structural Life-to-hand only, an explicit private destination policy on the real movement/payment primitive models the printed hand resource. Actual ST13 replacement still uses its real deck destination, finishes COST unpaid, and never supplies an imagined suffix resource. Optional field substitutes likewise remain separate from printed payment. Existing real replacement scanning/probing owns legal choices; repeating that work inside the boolean query would not change the structural gate and would duplicate a decision without a caller.
