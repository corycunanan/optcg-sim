# Leg 7 — FAQ rulings: timing and triggers

## Verdict

The proposal's §7 table covers the core turn-player order (§8-6-1, §8-6-1-1), the End Phase wave order (§6-6-1-1-2), and the Life Trigger exception (§8-6-2-1), so 10 of the 63 rulings below are FIXTURE-COVERED. The main problem is one CONFLICT: five FAQ rulings put an attacker's "deals damage" effect before the defender's Life Trigger, which contradicts the proposal's rule that ordinary triggers wait for damage processing to finish. There are 21 MODEL-GAP rows (battle Counter/Block windows, source-left pending work, continuous-effect layering, 8-6-3 activation-chain windows, game start, Refresh Phase, simultaneous-K.O. snapshots, and per-player order inside one instruction) and 31 FIXTURE-NEEDED rows, which the proposal's model can handle but no fixture asserts.

Counts: FIXTURE-COVERED 10, FIXTURE-NEEDED 31, MODEL-GAP 21, CONFLICT 1 (total 63).

Scope note: the FAQ scan used every Q/A pair in the remaining files that matched the requested patterns (405 pairs, read in full, then filtered to execution-order or pending-work content). Rulings that only describe card text were dropped. Rule sections are from docs/rules/rule_comprehensive.md. Where no rule number exists in the collected text, the row says so.
