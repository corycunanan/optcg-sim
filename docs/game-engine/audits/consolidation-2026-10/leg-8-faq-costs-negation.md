# Leg 8 — FAQ rulings: costs, replacements, negation, DON!!, base power

## Verdict
I read the six named FAQ files in full and matched 17 patterns across the other 33 FAQ files with six lines of context each, then classified 93 rulings: 67 FIXTURE-NEEDED, 17 MODEL-GAP, 8 COVERED, and 1 CONFLICT. The proposal covers the paid-versus-substituted split for costs and replacements (§4C, §10), but it names no batch-replacement, negation-scope, base-power layer, or cost-layering semantic, so those need model work before Phase 3. The one CONFLICT is the §4B sentence that cost sequences are not all-or-nothing, which contradicts rule 8-3-1-3 for activation costs.

## CONFLICT detail

**C1 (R01, ST06-012 Monkey.D.Garp, qa_st-06.md; also R02 OP11-024 Aladine, qa_op11.md).**

- FAQ: "Activation costs cannot be paid only in part. If a part or all of the activation cost cannot be paid, then the effect cannot be activated."
- Rule 8-3-1-3: "If it is not possible to pay some or all of the activation cost, the activation cost to activate the effect cannot be paid at all." Rule 8-3-1-3-1 allows partial payment only after the player has already activated the effect and then becomes unable to finish.
- Proposal §4B: "Do not assume every cost sequence is an all-or-nothing database transaction. Distinguish initial feasibility from becoming unable to finish after payment has begun. Existing cost staging is useful implementation work to evaluate, not a rule that must dictate the redesigned behavior."
- Why it conflicts: §4B makes all-or-nothing an open question. For activation costs, rule 8-3-1-3 settles it at feasibility time. Only the after-start case in 8-3-1-3-1 is partial. §4B should state that rule for activation costs and keep the open question for resolving-effect instructions (rule 1-3-2 "perform as many as possible").
- Fixture: Garp with 0 hand cards. Expect the effect refused and no rest.
