Shape Language — Specimens

CSS-only builds of the closed shape vocabulary (SHAPE-LANGUAGE.md), from the Guildrun / TFT / League / Overwatch references. Angle discipline: 45° chamfers, 90° pennant apexes, 120° hex corners. Rounded geometry appears only on card stand-ins.

1 · Chamfered panel + L-brackets

Panel · Tier 2

Two-layer clip-path: outer layer is the gold hairline, inner layer the surface. Brackets sit on the unclipped wrapper. Interior dead flat. --ch-3 (12px) cuts.

Layout-scale divider only (Overwatch's section split). Never used to decorate a component.

9 · Figure-ground thesis

The point of the whole system: inside angular chrome, the card is the only rounded rectangle in view. It advances; the frame recedes. No glow, no lift, no border needed.

Implementation notes: borders on clipped elements use the two-layer technique (outer = edge, inner = surface); focus rings need an inset layer because outline ignores clip-path; hit targets stay rectangular where shapes get small; inside ScaledBoard (~0.59×) hairlines and 4px chamfers must be scale-compensated.
