OPTCG Typography — Type Ramp

Living specimen for docs/design/TYPOGRAPHY.md. Erode (display) and Public Sans (body) load from src/app/fonts/ — open this file from a checkout. Mono roles render in a system stand-in for Geist Mono. Text picks a role, not a size: if a combination isn't on this sheet, it isn't in the system.
