# OP15-EB04 FAQ re-extraction (OPT-957)

Date: 2026-11-09

## What changed

`docs/FAQs/faq_op15-eb04.md` was converted from `docs/FAQs/pdfs/faq_op15-eb04.pdf` by an earlier pass that merged columns of adjacent table rows. The PDF has a clean text layer, so every row was re-extracted with `pdfplumber` table extraction and compared entry by entry with the old Markdown (whitespace-normalized).

- The PDF has 99 rulings. The old file held 97, because two rows had been merged into neighbours, and four entries sat under empty `##` headings.
- 80 rulings matched the PDF exactly and were kept unchanged.
- 19 rulings were rewritten from the PDF and are marked `_Corrected (OPT-957)._` in the file. One of them (OP15-038) only had a missing space in the card name.

## Re-classification of the previously excluded rulings

The October consolidation audit (`docs/game-engine/CONSOLIDATION-PROPOSAL-AUDIT-2026-10.md` §4K) excluded these rulings because their text was unreadable. Each is now classified against the current schema and engine code. "Handled" means the schema and the cited engine code agree with the ruling on reading; none of these was re-probed with a new test in this pass.
