# OPT-878 — remove unmatchable custom end-turn event

## Scope and acceptance evidence

Small type/documentation correction based on main `1dd5f5b9f42d262bb764ce0c3a3aab91b7939a06` in an isolated clone. Removed only `END_OF_YOUR_TURN` from `CustomEventType`; retained `KeywordTriggerType.END_OF_YOUR_TURN`. Replaced the schema README's invalid custom-event example with keyword guidance.

A recursive walk of every object in the production `AUTHORED_SCHEMAS` registry inspected nested `trigger.event` and `trigger.keyword` fields, including granted/nested effects. Results before and after are identical: **2474 schemas, zero custom-event consumers, 52 keyword consumers**. Examples include EB01-021, EB01-022, OP02-001, OP14-054, and OP17-047. `schema:check` confirms generated/source registry parity. This supports removal instead of adding runtime mapping.

Reproduce the inventory from repository root:

```sh
pnpm exec tsx -e '
import { AUTHORED_SCHEMAS } from "./workers/game/src/engine/authored-schemas.generated.ts";
const custom: string[] = [], keyword: string[] = [];
function walk(value: any, path: string) {
  if (!value || typeof value !== "object") return;
  if (value.trigger?.event === "END_OF_YOUR_TURN") custom.push(path + ".trigger");
  if (value.trigger?.keyword === "END_OF_YOUR_TURN") keyword.push(path + ".trigger");
  for (const [key, child] of Object.entries(value)) walk(child, path + "." + key);
}
for (const [id, schema] of Object.entries(AUTHORED_SCHEMAS)) walk(schema, id);
console.log({ schemas: Object.keys(AUTHORED_SCHEMAS).length, custom, keywordCount: keyword.length, keyword });
'
```

Runtime `triggers.ts` remains unchanged: keyword maps to `TURN_ENDED` and matches only when `event.playerIndex === sourceCard.controller`. No generated registry changes or authored-card migration needed.
