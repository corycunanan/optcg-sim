## Ticket (verbatim)

**Align finishReplacedLifeCost trash-event admission with the OPT-795 hand-trash rule**

Context: Found during OPT-822's integration review with OPT-795 (2026-09-15). `workers/game/src/engine/effect-resolver/cost/replaced.ts` (`finishReplacedLifeCost`, the terminal path for a replaced Life cost under ST13-003) filters scannable events with the pre-795 rule `e.type !== "CARD_TRASHED" || Boolean(getEventCardInstanceId(e))` and never calls `completeHandTrashCostSources`. The sibling paths (`resume/cost.ts` finishCostsAndRunActions, `resume/choice.ts` handleAwaitingOptionalResponse, `resolver.ts` resolveEffect) admit `isHandTrashByEffect(e)` and complete causal sources first.

Why it is latent, not live: independent scan of all 2472 authored schemas: 59 Life-cost blocks, none combines a Life cost with a hand-trash cost, and every Life cost is the last cost in its block. Empirical probes show a `CARD_TRASHED_FROM_HAND` watcher still fires in the replaced path because the event is published and scanned by the later pipeline batch. Consequences only if such a card is authored: the watcher queues in a later batch instead of alongside `pendingTriggers` (ordering drift), and an auto-paid hand trash after the source departed would lack causal attribution.

Fix:
- In `finishReplacedLifeCost`, call `completeHandTrashCostSources(events, state, sourceCardInstanceId, controller, refs)` before scanning and add `|| isHandTrashByEffect(e)` to the scannable filter, matching the sibling paths. Thread the frame's result refs through the callers that have them.
- Add a registered-card pipeline regression using a synthetic block `[TRASH_FROM_HAND, LIFE_TO_HAND]` under ST13-003 with a Kuroobi-style watcher, proving the watcher resolves in the same batch and with source attribution, for both Character and Event sources.
- Consider a schema-lint rule asserting Life costs stay last, so the inventory assumption is enforced rather than remembered.

Acceptance: Regression red before the change, green after; `pnpm --dir workers/game test` and `pnpm schema:check` green; consumer inventory unchanged for the current corpus.
