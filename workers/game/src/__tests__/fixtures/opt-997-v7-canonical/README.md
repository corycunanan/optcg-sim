# Canonical semantic replay corpus (synthetic only)

This is a prerequisite reader corpus for OPT-969 and the bounded OPT-997 ownership correction. Ordinary production inputs still write version 6. Native version 7 executes shared continuation semantics, including subsequent DON identity prompts. This directory does not enable the ordinary writer or deliver legacy promotion.

The manifest pins the actual isolated producer revision, complete payload bytes, a source patch from its reproducible base, and the generator command. Run that command in the isolated producer revision (or apply producer.patch to its stated base with separately installed frozen-lockfile dependencies). Default CI does not run the generator; it replays these saved bytes using the reader's real coordinator, lifecycle and repository.

There are 53 supported completion families: the prior 28 ownership/prefix/terminal/DON families; 20 canonical variants; one ordering-to-optional-decline-to-reoffer family; and four actual first-load legacy promotion families. The supported families have 127 pauses and 508 replay starts. One accepted legacy outcome-unknown family has one pause and four diagnostic starts; equal stuck output is not completion. A separate atomic-promotion-rejection record has no replay starts. Total: 55 payloads, 128 pauses and 512 starts, with the two diagnostic dispositions kept separate.

Malformed/missing action, unchecked owner, wrong phase, foreign/duplicate/missing IDs, wrong printed destination, malformed Life encoding and invalid fixed sentinel reject at live and every embedded/separate undo ingress, including entries beyond retained history. Valid absent outcomes remain unresolved; they are never inferred.
